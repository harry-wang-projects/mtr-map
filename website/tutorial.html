Controls for the editor

Key controls:

  • a/d: Previous/next checkpoint
  • w/s: Previous/next station
  • space: New station
  • q: Change position of currently selected station/checkpoint
  • e: Add a checkpoint in front of currently selected station/checkpoint
  • c: Center on currently selected station/checkpoint
  • r: Set currently selected station/checkpoint to the first station on the current branch
  • f/v: Move checkpoints of currently selected station up/down
  • u: Update map
  • k: Calculate progresses/travel times based on speed/acceleration
  • l: Save JSON
  • t: Add timetable entry
